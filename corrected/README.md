# The built files

These are web pages: open them in a browser, where hovering over (or tapping) a marked word shows its
popup. GitHub's file view shows their source instead. Read them online at
<https://jorgecaa.github.io/pts-gretil-ng/>.

Each file keeps the name of the GRETIL file it is built from (`dighn1ou.htm`: Dīgha-nikāya I,
`samyu4ou.htm`: Saṃyutta-nikāya IV). The volume of each file is given in the
[list of volumes](../README.md#volumes) of the README.

These files are written by `build.py`; they are not edited by hand.
